板块一 · 三个 Agent 作品

把 AI 能力转化为 SMB 客户能理解的效率提升场景

三个 Agent 分别对应政策资金、内容营销、项目研究，适合中小企业在低 IT 投入下快速验证 AI 价值。

政策申报建议书 Agent

面向科技型中小企业，输入企业基本信息、技术方向、资质材料和政策文本，输出申报匹配建议、 申报材料大纲、优势补强建议和风险提醒。

  • 客户价值：降低政策筛选和材料初稿成本，帮助企业更快判断申报优先级。
  • 能力体现：政策文本理解、信息抽取、模板化输出、风险项归纳。
  • 阿里云迁移：可用通义千问 + 向量检索 + OSS 文档库形成企业政策知识库。

科技成果领域推文写作 Agent

面向科研机构、技术服务公司或园区运营方，输入科技成果简介、目标受众和传播渠道，生成公众号、 视频脚本或销售跟进素材。

  • 客户价值：把偏技术的成果材料转化为可传播、可获客的营销内容。
  • 能力体现：受众分层、内容结构化、卖点提炼、语气风格控制。
  • 阿里云迁移：可结合百炼应用、内容审核和企业素材库形成营销内容助手。

项目研究 Agent

面向售前调研、行业研究或项目立项，围绕一个项目主题输出背景、政策、竞品、商业模式、 技术路线和行动建议。

  • 客户价值：缩短项目早期调研周期，为销售拜访和方案设计提供资料底座。
  • 能力体现：研究框架设计、多来源信息组织、结论归纳和下一步建议。
  • 阿里云迁移：可沉淀为 SMB 客户行业洞察库，辅助商机识别和方案推荐。

重点项目

项目 A：完整解决方案销售打单流程

建议选择一个从线索发现、需求诊断、方案设计、POC/测试、商务推进到交付复盘都参与过的项目。

1. 线索与客户画像 识别客户业务场景、预算来源、关键部门和决策链。
2. 需求诊断 把“买设备/系统”的表层需求转化为网络可靠性、运维效率、成本控制等业务目标。
3. 方案设计 协同售前形成产品组合、架构图、分阶段建设路径和价值测算。
4. 竞争与异议处理 围绕价格、性能、交付、服务、品牌风险进行差异化回应。
5. 成交与复盘 沉淀客户画像、行业话术、可复用材料和后续增购机会。

板块三 · 阿里云四个场景学习

把产品学习转化为 SMB 客户可落地的方案包

RAG 知识库

适用于企业制度、产品手册、售后 FAQ、政策资料等知识问答。

关键表达：文档解析、向量化、召回、重排、答案溯源。

RAG 知识库 + Tair 缓存

适用于高频问答、客服助手、内部知识助手，提升响应速度并降低成本。

关键表达：热点问题缓存、语义缓存、降本增效、体验稳定性。

LoRA 微调

适用于企业私有话术、行业术语、固定格式报告和特定风格内容生成。

关键表达：小样本、低成本、参数高效微调、评测集设计。

万小智

适用于企业快速搭建智能客服、营销问答、业务咨询等智能体入口。

关键表达：低门槛配置、业务知识接入、多渠道服务、运营闭环。

Transformer、TensorFlow、PyTorch 理解

TensorFlow/PyTorch：重点讲清深度学习框架在张量计算、自动求导、 模型训练、部署推理中的作用，以及 PyTorch 更常用于研究迭代、TensorFlow 常见于工程部署的差异。

部署方案

当前版本是纯静态站点，部署门槛低，适合快速对外访问

推荐优先使用阿里云 OSS 静态网站托管；如果想最快上线，也可以使用 Vercel、Netlify、 GitHub Pages 或任意 Nginx 静态服务。

阿里云 OSS 静态网站

  1. 创建 OSS Bucket，读写权限选择私有，之后配置公共读或 CDN 回源。
  2. 开启静态网站托管，默认首页设置为 index.html。
  3. 上传 index.html、styles.css、script.js。
  4. 绑定自定义域名并配置 HTTPS 证书。

低成本快速部署

  1. Vercel/Netlify：导入 GitHub 仓库，构建命令留空，发布目录选择根目录。
  2. GitHub Pages：选择当前分支根目录发布。
  3. ECS/Nginx：把三个静态文件放入站点根目录即可。
