# 阿里云 SMB 解决方案二面个人展示站

这是一个面向阿里云 SMB 事业部解决方案二面的候选人个人展示网站。站点采用纯静态 HTML/CSS/JavaScript 实现，无需构建步骤，适合快速部署到阿里云 OSS、GitHub Pages、Vercel、Netlify 或任意 Nginx 静态服务。

## 页面内容结构

网站按照“价值主张 - 证据 - 场景迁移”的面试叙事组织：

1. **三个 Agent 作品**
   - 政策申报建议书 Agent
   - 科技成果领域推文写作 Agent
   - 项目研究 Agent
   - 重点表达：业务问题、输入输出、客户价值、可迁移到阿里云的技术方案。

2. **锐捷网络两个项目**
   - 重点项目用于展示完整解决方案销售打单流程。
   - 补充项目用于展示行业覆盖、协同能力或复杂客户推进经验。
   - 建议补充真实字段：客户行业、项目金额、销售周期、关键竞争点、成交结果。

3. **阿里云四个场景学习**
   - RAG 知识库
   - RAG 知识库 + Tair 缓存
   - LoRA 微调
   - 万小智
   - 重点表达：SMB 客户场景、产品组合、降本增效路径。

4. **ACP 考纲框架型知识内容**
   - 阿里云云计算 ACP：ECS、VPC、SLB、OSS、RDS、Tair、安全、监控、成本优化。
   - 阿里云大模型 ACP：通义千问、百炼、RAG、智能体、微调、推理服务、应用集成。

5. **AI 工程理解**
   - Transformer 架构
   - TensorFlow
   - PyTorch
   - 重点表达：能用业务语言解释技术原理，并迁移到售前方案沟通。

## 本地预览

任选一种方式：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以直接用浏览器打开 `index.html`。

## 阿里云 OSS 静态网站部署

1. 登录阿里云控制台，创建 OSS Bucket。
2. 上传以下文件到 Bucket 根目录：
   - `index.html`
   - `styles.css`
   - `script.js`
3. 在 Bucket 基础设置中开启静态网站托管。
4. 默认首页设置为 `index.html`。
5. 根据访问策略选择：
   - 临时演示：配置公共读。
   - 正式展示：建议使用 CDN 回源 OSS，并绑定自定义域名和 HTTPS 证书。

## 其他快速部署方案

- **Vercel / Netlify**：导入 GitHub 仓库，构建命令留空，发布目录选择仓库根目录。
- **GitHub Pages**：在仓库设置中选择当前分支和根目录发布。
- **ECS + Nginx**：把三个静态文件复制到 Nginx 站点目录。
