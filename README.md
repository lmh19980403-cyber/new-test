# 公众号推文生成器

这是一个无依赖静态网页，把“公众号纯文字写作 Skill”做成可直接使用的内容生成工具。

## 功能

- 解读 Skill 的核心定位、内容主线、口吻和合规边界
- 支持粘贴大段推文写作素材
- 按 8 套文章模板生成完整大模型提示词
- 可选配置 OpenAI 兼容 Chat Completions API，直接生成 Markdown 推文
- 自动统计素材字数、提示词字数和生成稿中的 `【待填】` 项
- 支持一键复制提示词和生成结果

## 使用方式

直接打开 `index.html` 即可使用。

也可以用任意静态服务器预览：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## API 说明

页面默认不绑定任何模型服务。你可以：

1. 只生成提示词，复制到常用大模型中使用
2. 填写 OpenAI 兼容接口：
   - API Endpoint，例如 `https://api.openai.com/v1/chat/completions`
   - Model，例如 `gpt-4.1`、`deepseek-chat` 等
   - API Key

API Key 仅保存在当前浏览器的 `localStorage` 中。若部署到公开环境，建议改为后端代理，避免在浏览器中暴露密钥。

## 发布前提醒

生成内容必须人工复核：

- 事实、金额、人名、合作关系、专利、联系方式
- 创始人/科学家/合作方金句是否有真实来源
- 是否存在广告法极限词或金融收益承诺
- 所有 `【待填】` 项是否已替换
